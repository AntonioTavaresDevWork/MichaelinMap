# Feedback Marketing — UI Kit

Recriação hi-fi do site institucional da Feedback Comunicação no **novo sistema visual** (dark + accent lime, baseado no WisePEI).

O site público atual (`feedback.com.vc`) é um holding page WordPress/Elementor. Esta é a **proposta de rebrand visual**, não uma recriação fiel do Elementor atual — preserva **copy e estrutura narrativa** (Construa / Contribua / Conquiste), moderniza o visual.

## Componentes

- `Header.jsx` — nav fixa com blur
- `Hero.jsx` — headline editorial + CTAs + placeholder de ilustração
- `ServicesGrid.jsx` — três pilares (SaaS, Power BI, Automação)
- `BigIdea.jsx` — seção "Você tem uma grande ideia?"
- `Footer.jsx` — rodapé minimalista

## Abrir

`index.html` — monta a home completa com interação leve (menu ativa, scroll suave, form submit fake).
